# Lookdev skill

- Use physically plausible PBR values when realism is requested.
- Keep material scale consistent with object scale.
- Separate macro form, meso breakup, and micro-normal detail.
- Treat seams, labels, dirt, wear, and roughness variation according to the brief rather than adding generic grunge.
- Validate UV stretching and texel density when authored textures are required.
- Test materials under neutral evaluation light before designed lighting.
- Record texture dependencies and resolution.
