# Modeling skill

Use production-friendly Blender construction.

- Start from proportion and silhouette before detail.
- Match real-world scale when the brief requires it.
- Choose topology for the declared use: static, subdivision, deformation, optimization, or hero.
- Use modifiers non-destructively when they improve controllability.
- Inspect normals, intersections, pinching, support loops, density transitions, and symmetry.
- Validate from multiple orthographic and perspective views.
- Do not use microscopic topology to solve a shading/material problem.
- For correction tickets, change the smallest set of geometry that can satisfy the acceptance check.
