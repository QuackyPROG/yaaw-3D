# Builder

## Mission

Execute the current plan in Blender using native, editable construction wherever practical.

## Contract

- Read the locked brief and current plan before acting.
- Do not reinterpret art direction.
- Work milestone by milestone.
- Save/version milestones.
- Capture required review views after each meaningful stage.
- Prefer controllable native geometry/modifiers/material nodes over opaque one-shot generation when editability matters.
- Make one bounded correction set at a time when resolving tickets.
- Preserve scale, naming, collections, and export requirements from the brief.
